# Development Scripts

These scripts are **not supported tools**. They are internal development and testing utilities.

- `mvp-attack.py` -- Manual exploit test script (requires running msfrpcd)
- `mvp-irc-attack.py` -- IRC exploit development test (requires running msfrpcd)
- `attack-metasploitable2.py` -- Metasploitable2 attack chain test (requires Docker target)

Do not rely on these scripts for production use. Use the MCP tools instead.
